# 📝 Personal Planner

Консольний персональний планувальник на Python. Дозволяє додавати завдання, переглядати їх, видаляти, позначати виконаними та шукати за назвою. Усі дані автоматично зберігаються у файл `tasks.json`.

## ✨ Можливості

- ➕ Додавання завдань (назва, дата, опис)
- 📋 Перегляд усіх завдань
- 🗑 Видалення завдання за ID
- ✅ Позначення завдання виконаним
- 🔍 Пошук за назвою (без урахування регістру)
- 💾 Автоматичне збереження та завантаження даних

## 🖥 Інтерфейс

```
    ╭────────────────────────────────╮
    │    Персональний планувальник   │
    ╰────────────────────────────────╯
     ────────────────────────────────
      [1] ➜  Додати завдання
      [2] ➜  Переглянути всі завдання
      [3] ➜  Видалити завдання
      [4] ➜  Позначити завдання виконаним
      [5] ➜  Пошук за назвою
      [0] ➜  Вийти
     ────────────────────────────────
```

## 🚀 Встановлення та запуск

Потрібен **Python 3.8+**. Зовнішні залежності не потрібні.

```bash
git clone https://github.com/theMixtape/personal-planner.git
cd personal-planner
python main.py
```

## 📖 Приклад використання

```
Оберіть дію: 1
Введіть назву ➜  Купити продукти
Введіть дату ➜  25
Введіть опис ➜  Молоко, хліб, яйця
[!] Додано завдання: [ID: 1] Купити продукти
    Дата: 25
    Опис: Молоко, хліб, яйця
    Статус: ✘ не виконано
```
